# Visual references

What each reference is for. Take the principle, not the specifics: no copy, photos, logos or layouts lifted whole.
Where a reference uses something Taste Skill bans (monospace body, cream ground with terracotta, pill buttons,
eyebrow labels), keep the idea and leave that part out.
